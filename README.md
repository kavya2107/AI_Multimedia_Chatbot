
# AI Multimedia Chatbot

AI Multimedia Chatbot is a full-stack application developed using React and FastAPI that enables users to upload PDF documents, generate summaries, and interact with document content through a chatbot interface.

The application extracts text from uploaded PDFs, processes the content, and allows users to ask questions related to the document. The system then returns relevant answers dynamically.

## Features

* PDF Upload Functionality
* Text Extraction from Documents
* AI-Based Summary Generation
* Document Question Answering
* Interactive Chatbot Interface
* Full-Stack Integration using React and FastAPI

## Tech Stack

Frontend:

* React.js
* Axios

Backend:

* FastAPI
* Python

Libraries:

* PyPDF2
* Transformers
* Uvicorn
